# 🍿 سهرة بلس | قاعة السينما الافتراضية والتزامن اللحظي (Hyperbeam Cinema Sync)

منصة مشاهدة مشتركة (Co-watching) مجانية بالكامل وغير محدودة، بديلة لـ Hyperbeam، تتيح للأصدقاء إنشاء قاعة سينما افتراضية والسهر لمشاهدة الأفلام والفيديوهات معاً بالتزامن اللحظي من أي جهاز (موبايل، تابلت، كمبيوتر، شاشات ذكية).

---

## ✨ المميزات الرئيسية (المرحلة الأولى)
1. **تزامن المشغل الفائق (Zero-Latency Sync):** مزامنة فورية بالمللي ثانية لتشغيل وإيقاف وتقديم وتأخير الفيديو وسرعة العرض بين جميع الأصدقاء.
2. **مصادر فيديو متعددة:**
   * 🔗 **روابط مباشرة وسحابية:** تشغيل روابط MP4 و WebM و HLS وروابط التخزين السحابي.
   * 📁 **ملفات محلية من الجهاز:** إمكانية تشغيل أي فيلم محلي موجود على الهاتف أو الكمبيوتر بالتزامن.
   * 🖥️ **مشاركة الشاشة مع الصوت:** مشاركة أي نافذة أو موقع خارجي مع الأصدقاء بنقرة زر وبصوت النظام الداخلي.
   * 💬 **دعم ملفات الترجمة (SRT / VTT):** سحب وإفلات ملف الترجمة العربية ليعمل فوراً على العرض.
3. **تصميم سينمائي أنيق (Netflix-Style Dark Theme):** ألوان نتفليكس (الأسود والأحمر)، واجهة متجاوبة ومريحة للعين.
4. **شات تفاعلي وتفاعلات تعبيرية طافية (Live Reactions):** تفاعلات حية تطفو على الشاشة (🍿 😂 ❤️ 😱 🔥 👏).
5. **نظام صلاحيات المضيف (Host Control Lock):** إمكانية حصر التحكم في يد منشئ القاعة أو فتحه لجميع الحضور.

## 🚀 طريقة التشغيل محلياً (Local Setup)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل السيرفر:
```bash
npm start
```

### 3. فتح القاعة:
توجه إلى المتصفح وافتح:
```
http://localhost:3000
```
أو ادخل مباشرة باسم قاعة محددة:
```
http://localhost:3000/?room=sahra-vip
```
